# Project Visualizations

This folder contains the charts generated during the Strategic Planning and Data Exploration in Logistics project.

The visualizations demonstrate the results of the Python-based data analysis, including:

- Top-selling products by quantity.
- Daily order trends.
- Weekday order patterns.
- Moving-average demand forecasting.
- Distribution of daily order volumes.
- Country-wise sales performance.
- High-demand days.

These charts support the findings and recommendations presented in the final project report.
