# Project Report

This folder contains the final Word report for the Strategic Planning and Data Exploration in Logistics project.

## Report Contents
- Project abstract and objectives.
- Dataset description and methodology.
- Data cleaning and preparation.
- Exploratory data analysis.
- Product and country-wise sales performance.
- Daily demand patterns and high-demand periods.
- Moving-average forecasting and evaluation metrics.
- Recommendations for logistics planning.
- Project limitations and future improvements.
- References and glossary.

## Purpose
The report documents the analysis process, summarizes the main findings, and explains how transaction data can support inventory planning, demand monitoring, and operational decision-making.

## File Format
The final report is provided in Microsoft Word format (`.docx`).
