# Python Code

This folder contains the Python script used for the Strategic Planning and Data Exploration in Logistics project.

## File
- `logistics_analysis.py` — performs data cleaning, exploratory data analysis, sales calculations, demand analysis, moving-average forecasting, forecast evaluation, and chart generation.

## Libraries Used
- Pandas — data manipulation and analysis.
- Matplotlib — data visualization.
- NumPy — numerical operations, where required.
- OpenPyXL — Excel file reading support, if required by the script.

## How to Run
1. Install Python on your computer.
2. Install the libraries required by the script.
3. Make sure the Online Retail dataset is available at the file path expected by the script.
4. Open the project in VS Code.
5. Run `logistics_analysis.py`.

## Purpose
The script converts retail transaction records into useful summaries and visualizations to support demand analysis and logistics planning.
